## Selected projects

### [Brownpak](https://github.com/saridut/brownpak) — Polymer simulation

Fortran software for Brownian dynamics simulations of bead-spring polymers
with hydrodynamic interactions. Includes explicit and semi-implicit
integration, Cholesky and Krylov methods for Brownian force generation,
and several neighbour-search methods.

[User guide](https://saridut.github.io/brownpak/page/index.html)

### [MCPak](https://github.com/saridut/mcpak) — Monte Carlo sampling

Fortran software for sampling coarse-grained polymer configurations,
including linear, ring, and graft architectures, with several interaction
models and Monte Carlo moves.

### [FloriPy](https://github.com/saridut/floripy) — Multibody dynamics

Python software for the overdamped dynamics of articulated rigid bodies
in viscous flows. Uses constrained multibody dynamics and hydrodynamic
drag to study the motion and folding of patterned sheets.

### [NPLSizer](https://github.com/saridut/nplsizer) — Microscopy image analysis

Python application for semi-automated sizing of rectangular nanoplatelets
from microscopy images. Combines image processing, segmentation, and
interactive correction using napari, scikit-image, and OpenCV.

### [Ribbon](https://github.com/saridut/ribbon) — Nanoplatelet geometry

Python package for generating idealized nanoplatelet shapes and atomic
configurations directly from geometrical parameters. Supports helical,
helicoidal, cylindrical, and spiral shapes for structural and scattering
analysis.

### [Rotlib](https://github.com/saridut/rotlib) — Rotation representations

A numerical library with C, Fortran, and Python implementations for
converting between quaternions, Euler angles, rotation matrices, and
axis-angle representations. Includes tests and API documentation.
